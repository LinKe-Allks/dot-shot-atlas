# Blender Camera Motion Library

Seven real Blender-rendered motion studies, 640 × 360, 12 fps, 3 seconds each. The copper orbital sculpture, foreground markers, depth columns and floor grid expose camera perspective and parallax.

## Reproduce

Requires Blender 4.3.2, FFmpeg and Python 3. The shell runner uses Blender from PATH; set BLENDER to override its executable and PYTHON to override Python 3. Run `bash render_all.sh` in this directory. Individual render: `blender -b -t 4 --python render_camera_library.py -- orbit`. `SAMPLE_ONLY=1` renders a midpoint test frame only. Each clip has an independent fully animated `.blend` source.

## Rendering

Blender Workbench studio lighting, material colors, shadows, cavity and 8-sample antialiasing. This is actual offline Blender rendering, not a browser/WebGL imitation. Warm and cool area lamps are retained in each scene for optional Eevee/Cycles re-rendering; they are not used by the Workbench renderer. H.264/yuv420p MP4s use fast-start for browser playback.

## Motion definitions

- **dolly-in:** Camera moves physically toward the subject (16 m → 8 m), constant 42 mm lens, with slight vertical descent and tracking aim.
- **dolly-out:** The same physical path in reverse, constant 42 mm lens.
- **pan:** Stationary camera position, 24° horizontal yaw sweep, constant 42 mm lens. No translation.
- **truck:** 7 m lateral translation at fixed height, orientation and 38 mm focal length. No tracking pan, so parallax is especially clear.
- **orbit:** 84° arc at 12 m radius, fixed height and 42 mm lens, continuously aimed at the subject.
- **crane-reveal:** 7.9 m vertical rise, fixed horizontal position and 42 mm lens, tracking tilt reveals the floor and spatial arrangement.
- **zoom:** Stationary camera position and orientation; lens changes 28 mm → 65 mm. No perspective/parallax change.

The motions have smooth ease-in/ease-out endpoints. They do not form seamless loops; the website may replay them with a visible reset, or play forward/backward.

`manifest.json` gives technical notes, source/clip/poster paths, resolution, duration and Blender version. This source-only bundle does not include videos, posters, frame PNGs or render logs. Run the script to generate those outputs. Posters use frame 18.

## Public-source hygiene

The seven included .blend files use relative render paths and neutral file-browser directories. All camera animation was preserved and verified after reopening the saved files. manifest.json contains relative output names; video and poster entries describe outputs generated by the scripts, not files shipped here. No private workspace information, Notion links or user data is included.
