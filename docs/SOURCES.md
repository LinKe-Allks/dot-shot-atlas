# 来源与使用边界

核验日期：2026-10-24。这里整理的是电影语言和官方提示指南，并非模型成功率报告。

- [Runway Gen-4 提示指南](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)：简单迭代、正向描述、图生视频的动作重点。
- [Runway 相机术语与示例](https://help.runwayml.com/hc/en-us/articles/47313504791059-Camera-Terms-Prompts-Examples)：官方镜头表达参考。
- [Google Veo 提示指南](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/video-gen-prompt-guide)：提示组成、相机与光学表达及可靠性边界。
- [Adobe 镜头与角度](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles.html)：景别与叙事用途。
- [StudioBinder Camera Movements](https://www.studiobinder.com/camera-shots/camera-movements/)：摄影机运动分类。
- [StudioBinder Rack Focus](https://www.studiobinder.com/blog/rack-focus-shot-camera-movement-angles/)：焦平面切换。
- [Adobe 转场说明](https://helpx.adobe.com/premiere/desktop/add-video-effects/apply-video-transitions/transitions-overview.html)：剪辑点、素材余量与后期连接。
- [Match Cutting 研究论文](https://arxiv.org/abs/2210.05766)：构图和动作匹配的概念。

每条内容中的情绪效果、用途和避坑也包含制作判断，不应理解为某种角度必然产生固定心理效果。提示词均未逐模型生成测试。网站图片为原创教学示意，运动视频为自行搭建场景的 Blender 渲染，不是电影剧照或 AI 生成结果。
